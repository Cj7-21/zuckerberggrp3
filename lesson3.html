📖 Lesson 3: Evolution of the Web & Types of Websites

Learning Objectives

  • Define the World Wide Web and recognize Tim Berners‑Lee’s contribution.
  • Describe Web 1.0, Web 2.0, and Web 3.0.
  • Compare the differences among the three generations of the Web.
  • Identify and explain the different types of websites.

What is the World Wide Web?

The World Wide Web (WWW) is a collection of interconnected webpages and websites that people access through the Internet using web browsers.

Tim Berners‑Lee — Computer Scientist and Professor known as the inventor of the World Wide Web.

Evolution of the Web

Generation Name Main Purpose Characteristics Examples
Web 1.0 Static Web / Read‑Only Read Static webpages, one‑way communication, no interaction, information owned by website owner Old static information sites
Web 2.0 Dynamic Web / Read‑Write Read & Write Social media, online collaboration, user‑generated content, likes, comments, real‑time communication Facebook, YouTube, Wikipedia
Web 3.0 Semantic Web / Read‑Write‑Own Read, Write & Own Artificial Intelligence, personalization, smart search, machine learning, decentralization Metaverse, NFT marketplaces, AI search engines

Different Types of Websites

Type Description Examples
Static Website A website with fixed content that remains the same for all visitors; needs a web developer to update Old information sites
Dynamic Website Content changes based on user interaction, time, or database information; interactive and updated regularly Facebook, YouTube
Personal Website Created by an individual to share personal information, hobbies, portfolios, or blogs Personal portfolio blogs
Business Website Designed to promote a company, its products, services, contact information, and brand identity Company official sites
E‑Commerce Website Allows users to buy and sell products or services online through secure payment systems Shopee, Lazada
Educational Website Created for teaching, learning, training, and academic purposes; provides resources, classes, and assessments Google Classroom, EdX
Government Website Managed by government agencies to provide public information, announcements, and online government services gov.ph sites
Entertainment Website Created to entertain users through videos, music, games, movies, or streaming services Netflix, YouTube
Social Networking Website Allows users to create profiles, connect with others, communicate, share photos/videos, and build online communities Facebook, Instagram
News Website Publishes current events, news articles, weather reports, sports updates, and journalistic content CNN, ABS‑CBN News
Search Engine Website Helps users search and locate information, websites, images, videos, and documents on the Internet Google, Yahoo
Media Sharing Website Allows users to upload, store, and share multimedia content such as photos, videos, music, or presentations YouTube, Vimeo
Web Application Functions like software allowing users to perform tasks online instead of simply viewing information G Suite, Canva
